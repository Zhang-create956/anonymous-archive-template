# Anonymous Personal Archive Template

Standalone GitHub Pages template based on the original archive-style layout.

- No personal name, age, school, employer, contact, portrait, or project history is included.
- The **个人经历** card opens an intentionally blank content panel.
- Replace the placeholder copy in `site/index.html` only with information you explicitly want to make public.

## GitHub Pages deployment

The workflow at `.github/workflows/deploy.yml` deploys `site/` when changes are pushed to `main`.

In the GitHub repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
